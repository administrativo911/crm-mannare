CRM MANNARE — APP DE CELULAR (PWA) · publicação no GitHub Pages

O que tem nesta pasta
  index.html            o CRM (já preparado para virar app)
  manifest.webmanifest  nome, cores e ícones do app
  sw.js                 permite instalar e abre o app mais rápido
  icons/                ícones do app (Android, iPhone e computador)

1. Subir os arquivos no GitHub
  - Abra o repositório do CRM > "Add file" > "Upload files".
  - Arraste index.html, manifest.webmanifest, sw.js e a PASTA icons
    para a mesma pasta onde hoje estão o index.html e o config.js.
  - NÃO apague nem substitua o config.js.
  - Clique em "Commit changes". Em 1 a 2 minutos o GitHub Pages publica
    (aba "Actions" mostra "pages build and deployment" em verde).

2. Supabase (login com Google dentro do app)
  - Supabase > Authentication > URL Configuration > Redirect URLs.
  - Adicione o endereço do CRM com curinga, por exemplo:
      https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/**
    (ou https://seu-dominio/** se o Pages usa domínio próprio)

3. Apps Script
  - Nada muda. Os e-mails automáticos de licença e a ponte de propostas
    continuam iguais; o app nunca guarda essas respostas no aparelho.

4. Atualizações futuras
  - Ao subir um index.html novo, abra o sw.js e troque 'mannare-v1'
    por 'mannare-v2' (depois v3...). Assim todos recebem a versão nova.
  - O GitHub Pages pode levar até ~10 minutos para entregar a versão nova.

Como instalar
  Android (Chrome): abra o endereço > menu (⋮) > "Instalar app".
  iPhone (Safari):  abra o endereço > Compartilhar > "Adicionar à Tela de Início".
  Computador (Chrome/Edge): ícone de instalar na barra de endereço.
